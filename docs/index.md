# 🎓 StudiBro

AI-powered study companion for note summarization, quiz generation, and flashcard creation.

## Quick Links

📖 [Getting Started](getting-started.md) • 🔌 [API Docs](api-documentation.md) • 🏗️ [Architecture](architecture.md)

## Features

✨ **AI Summaries** - Condense any notes  
❓ **Auto Quizzes** - Test your knowledge  
📸 **OCR Scanning** - Digitize documents  
📚 **Flashcards** - Spaced repetition  
🏷️ **Organization** - Filter by subject & year  

## Tech Stack

**Frontend:** Flutter  
**Backend:** Django REST Framework  
**AI:** Google Gemini API  
**Database:** PostgreSQL  
**OCR:** Google ML Kit
