# Contributing

## Quick Start

1. Fork the repo
2. `git checkout -b feature/my-feature`
3. Make changes
4. `git commit -m "feat: description"`
5. Push and open PR

## Coding Standards

### Python
- Follow PEP 8
- Use type hints
- Add docstrings

### Dart
- Follow Dart style guide
- Meaningful variable names
- Comments on complex logic

### Commits
```
feat: add new feature
fix: resolve bug
docs: update documentation
style: format code
```

## Testing

**Backend:**
```bash
python manage.py test api
```

**Frontend:**
```bash
flutter test
```

## PR Checklist

- [ ] Tests pass
- [ ] Code follows standards
- [ ] Updated docs if needed
- [ ] No breaking changes
- [ ] Descriptive PR title

## Questions?

Open an issue on GitHub or ask in discussions.
